# 发票报销管理系统

基于 FastAPI 的增值税电子发票识别与报销管理系统，支持蓝牙扫描器快速采集、PC端实时管理、移动端便捷操作。

## 功能特性

### 核心功能
- **📷 扫描采集**: 支持蓝牙扫描器快速扫描发票二维码
- **📱 移动端**: 手机摄像头实时扫描发票
- **💻 PC端**: 发票管理、报销单管理、系统设置
- **🔄 实时同步**: 基于 WebSocket 的多端数据实时同步
- **🔐 HTTPS**: 支持 HTTPS 加密访问，保障数据安全

### 报销单管理
- **📋 报销单创建**: 选择部门、人员，填写报销事由
- **📄 发票关联**: 发票自动关联到报销单
- **📊 自动计算**: 自动计算发票数量和总金额
- **✅ 报销提交**: 草稿/已提交状态管理

### 基础数据管理
- **🏢 部门管理**: 创建和管理部门信息（部门编码、名称）
- **👤 人员管理**: 创建和管理人员信息（人员编码、姓名、所属部门）

### 智能识别
- **🔍 二维码解析**: 快速解析发票二维码，提取关键信息
- **🚫 重复检测**: 自动检测重复发票，提示但不中断扫描流程
- **📅 数据过滤**: 支持按年份、月份、部门、人员过滤发票

## 技术栈

### 后端
- **FastAPI** - 高性能 Web 框架
- **OpenCV** - 二维码检测和解析
- **WebSocket** - 实时通信
- **SQLite** - 本地数据存储
- **aiosqlite** - 异步数据库操作

### 前端
- **原生 HTML/CSS/JS** - 无依赖，轻量级
- **html5-qrcode** - 二维码扫描库
- **WebSocket Client** - 实时数据更新
- **MediaDevices API** - 摄像头调用

## 快速开始

### 1. 安装依赖

```bash
# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

### 2. 生成 SSL 证书（HTTPS 可选）

如果需要使用 HTTPS（手机摄像头需要）：

```bash
openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes \
  -subj "/C=CN/ST=Beijing/L=Beijing/O=Invoice/OU=IT/CN=your-server-ip"
```

### 3. 启动服务

```bash
# 方式一：直接运行
python -m backend.main

# 方式二：使用 uvicorn
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

服务启动后访问:
- **PC 端**: https://your-server-ip:8000
- **手机端**: https://your-server-ip:8000/mobile

**默认账号**:
- 用户名: `admin`
- 密码: `admin123`

### 4. 配置阿里云安全组

如果服务器在阿里云，需要在安全组中开放端口 8000：
- 协议: 自定义 TCP
- 端口: 8000/8000
- 授权对象: 0.0.0.0/0

## 使用说明

### PC 端功能

#### 1. 系统设置
首次使用需要配置基础数据：

1. **部门管理**
   - 点击"系统设置"
   - 创建部门（如：技术部，编码 IT）
   - 可以删除不需要的部门

2. **人员管理**
   - 创建人员（如：张三，编码 E001）
   - 选择所属部门
   - 可以删除不需要的人员

3. **账户设置**
   - 修改密码
   - 退出登录

#### 2. 发票管理
- 查看所有扫描到的发票
- 按年份、月份、部门、人员过滤
- 查看发票总数和总金额
- 删除单张发票或清空全部

#### 3. 报销单管理
- **新建报销单**: 填写报销单号、选择部门人员、填写报销事由
- **查看发票**: 点击"📄 查看发票"按钮查看报销单的发票明细
- **扫描发票**: 点击"📷 扫描"按钮进入扫描页面
- **删除报销单**: 删除报销单（发票自动解除绑定）

#### 4. 扫描页面（蓝牙扫描器）
- 自动聚焦输入框
- 使用蓝牙扫描器扫描发票二维码
- 自动提交并显示在发票明细区
- 自动计算发票数量和总金额
- 支持连续扫描
- 重复发票自动检测并提示
- 提交报销单

### 手机端功能

#### 1. 创建报销单
- 点击"+ 创建报销单"
- 填写报销单号、选择部门人员、填写报销事由
- 创建后自动进入扫描模式

#### 2. 扫描发票
- 点击"📱 开始扫描"启动摄像头
- 将发票二维码放入扫描框
- 自动识别并关联到当前报销单
- 查看已扫描发票列表
- 提交报销单

#### 3. 从相册选择
- 点击"🖼️ 或从相册选择二维码图片"
- 选择含有二维码的图片
- 自动识别发票信息

## 二维码格式

电子发票二维码标准格式：
```
01,发票代码,空,发票号码,价税合计,开票日期,校验码前6位,校验码后4位
```

示例：`01,31,,25312000000432294815,363.75,20251226,,577F`

| 字段位置 | 字段名 | 格式 | 示例 |
|---------|--------|------|------|
| 0 | 版本号 | 固定值 | 01 |
| 1 | 发票代码 | 数字 | 31 |
| 2 | 空字段 | - | - |
| 3 | 发票号码 | 20位数字 | 25312000000432294815 |
| 4 | 价税合计 | 带小数 | 363.75 |
| 5 | 开票日期 | 8位数字 | 20251226 |
| 6 | 空字段 | - | - |
| 7 | 校验码 | 可选 | 577F |

## 常见问题

**Q: 扫描器无反应？**
A:
1. 确保扫描页面已打开且输入框有焦点（绿色背景）
2. 检查扫描器是否正常工作（尝试在记事本中测试）
3. 确认扫描器以回车键结束

**Q: 提示"发票已存在"？**
A: 系统会自动检测重复发票号，同一张发票不能重复录入。这是正常保护机制。

**Q: 移动端无法使用摄像头？**
A: 浏览器要求使用 HTTPS 协议才能访问摄像头。请确保使用 `https://` 访问系统。

**Q: 数据存储在哪里？**
A: 数据存储在 `data/invoices.db` SQLite 数据库文件中。

**Q: 如何备份数据？**
A: 定期备份 `data/` 目录和 `cert.pem`、`key.pem` 文件即可。

**Q: 忘记密码怎么办？**
A: 可以直接修改 `backend/auth.py` 文件中的默认密码，或重新生成数据库。

**Q: 发票二维码识别失败？**
A:
1. 确保二维码完整清晰
2. 使用"测试扫描"按钮测试系统功能
3. 查看控制台日志获取详细错误信息
